# Student Grade Calculator

A simple Python program that calculates a student's total marks, percentage, and grade based on the marks entered for each subject.

## 📌 About the Project

This is a beginner-friendly Python project created to practice fundamental Python programming concepts such as functions, loops, lists, user input, conditional statements, and calculations.

The program asks for the student's name, number of subjects, and marks for each subject. It then calculates the total marks, percentage, and final grade.

## ✨ Features

- Enter student name
- Enter the number of subjects
- Enter marks for each subject
- Calculate total marks
- Calculate percentage
- Automatically calculate grade
- Display the final result

## 🛠️ Technologies Used

- Python 3
- Functions
- Lists
- For Loop
- Conditional Statements
- User Input

## 📊 Grading System

| Percentage | Grade |
|------------|-------|
| 90% and above | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | F |
